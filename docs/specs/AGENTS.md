Spec documents are source of product/design intent and requirements for big new features or changes. They include information like:

- goals
- non-goals
- architecture
- behavior
- UI/UX logic

### Spec Lifecycle

At the top of spec docs put lifecycle metadata:

```
**Status:** Done
**Accepted:** 2026-08-03
**Implemented by:** #101, #102, #103
**Supersedes:** None
```

**Status** Draft → Accepted → In Progress → Done → Superseded
